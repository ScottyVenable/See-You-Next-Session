# Development Roadmap (MVP)

**Project:** See You Next Session  
**Team:** 2 Developers (Prog/Design + Art/Writer)  
**Goal:** Playable MVP with 1 Tutorial Patient + 1 Challenge Patient.

---

## Phase 1: The Skeleton (Weeks 1-2)
**Goal:** Functional Core Loop with placeholder art.

*   **Programming:**
    *   [ ] Set up Unity Project & GitHub Repo.
    *   [ ] Implement `PatientProfile` and `Symptom` ScriptableObjects.
    *   [ ] Build the **Dialogue System** (Display text, click to create Token).
    *   [ ] Build the **Drag-and-Drop System** (Move tokens between Clipboard and Handbook).
*   **Design:**
    *   [ ] Write the full script for "Patient 1 (Tutorial - Anxiety)".
    *   [ ] Define the exact keywords for the tutorial.

## Phase 2: The Mechanics (Weeks 3-4)
**Goal:** Focus System and Synthesis Logic.

*   **Programming:**
    *   [ ] Implement **Focus Meter** (Drain on action, Restore on success).
    *   [ ] Implement **Focus Mode** (Post-processing vignette, hotspot detection).
    *   [ ] Code the **Synthesis Logic** (Check for contradictions).
*   **Art:**
    *   [ ] Sketch UI Wireframes.
    *   [ ] Create Base Character Sprites (Roughs).

## Phase 3: The Content & Art Integration (Weeks 5-6)
**Goal:** Replace gray boxes with real assets.

*   **Art:**
    *   [ ] Finalize Patient 1 Sprites + Symptom Overlays.
    *   [ ] Finalize Office Background.
    *   [ ] Create UI Assets (Clipboard, Meter, Tokens).
*   **Programming:**
    *   [ ] Integrate Art assets.
    *   [ ] Implement Audio Manager (SFX triggers).
*   **Writing:**
    *   [ ] Write script for "Patient 2 (Challenge - Bipolar)".

## Phase 4: The Polish & Loop Closure (Weeks 7-8)
**Goal:** Start-to-Finish Playability.

*   **Programming:**
    *   [ ] Implement **End of Session** Grading/Report Card.
    *   [ ] Main Menu & Pause Menu.
    *   [ ] Save System (Unlock next patient).
*   **Design:**
    *   [ ] Balance Focus costs (Playtesting).
    *   [ ] Adjust difficulty of Patient 2.

## Phase 5: MVP Release Candidate (Week 9)
*   [ ] Bug fixing.
*   [ ] Final build generation.
